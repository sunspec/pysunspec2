# Secure SunSpec Modbus TLS test PKI

This directory holds the certificate set used by the Secure SunSpec
Modbus (mbaps) TLS tests. Everything here is generated by
[`create_tls_certs.sh`](create_tls_certs.sh) — do not edit the PEM files
by hand; change the script and regenerate:

```sh
./create_tls_certs.sh
```

All keys are **ECDSA on the NIST P-256 curve**, which the mandatory
Secure SunSpec Modbus cipher suites require (ECDHE-ECDSA, P-256 —
SunSpecTCP-17/42/43/44). Client certificates carry the SunSpec **role
extension** at OID `1.3.6.1.4.1.50316.802.1`, an ASN.1 `UTF8String`
holding exactly one role (SunSpecTCP-29/30/31).

## Layout

```
tls_data/
  create_tls_certs.sh        regenerates everything below
  openssl/                   extension templates used by the script
  ca/                        shared trust anchors
    root_ca.{crt,key}
    server_inter_ca.{crt,key}   client_inter_ca.{crt,key}
    server_ca_chain.crt         (server_inter + root)
    client_ca_chain.crt         (client_inter + root)
  server/
    tls1_2/  server_valid.{crt,key}    valid server cert for TLS 1.2 tests
    tls1_3/  server_valid.{crt,key}    valid server cert for TLS 1.3 tests
    invalid/ server_expired.*          expired
             server_self_signed.*      not chained to a trusted CA
             server_foreign_ca.*       signed by an untrusted CA
             server_no_san.*           missing subjectAltName
  client/
    tls1_2/  client_readonly.*         role ReadOnlySunSpec
             client_gridservice.*      role GridServiceSunSpec
             client_netadmin.*         role NetworkAdministratorSunSpec
             client_superadmin.*       role SuperAdministratorSunSpec
    tls1_3/  (the same four roles, for TLS 1.3 tests)
    invalid/ client_no_role.*          no role extension (SunSpecTCP-32)
             client_malformed_role.*   role encoded as IA5String, not UTF8String
             client_self_signed.*      not chained to a trusted CA
             client_foreign_ca.*       signed by an untrusted CA
             client_expired.*          expired
  foreign_pki/
    foreign_root_ca.{crt,key}  an unrelated, untrusted CA used by the
                               multiple-PKI / reject-unknown-CA tests
```

The four client roles are the mandatory SunSpec roles (SunSpecTCP-22):
`ReadOnlySunSpec`, `GridServiceSunSpec`, `NetworkAdministratorSunSpec`
and `SuperAdministratorSunSpec`.

## Trust relationships

- A **server** validates client certificates against
  `ca/client_ca_chain.crt`.
- A **client** validates the server against `ca/server_ca_chain.crt`.
- The valid TLS 1.2 / TLS 1.3 leaf certificates are cryptographically
  identical in profile — an ECDSA P-256 certificate is not tied to a
  TLS version — but are kept in per-version directories so each test
  suite has a self-contained certificate set.
